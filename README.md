# Automated B2B Prospect List Scraper – YC SaaS Companies

**Freelance GTM Data Analyst and Clay & Data Specialist Project**  
**Q2 2024 | Delivered via Freelancer.com**

Production-ready B2B prospect list builder using Apify + Serper.dev enrichment that scraped YC companies and exported Clay-ready JSON.

### Business Impact
- Scraped and qualified **23 B2B/SaaS prospects** based on tags and descriptions  
- Enriched with real-time Google data (websites, founders, Instagram signals)  
- Delivered **Clay-ready JSON** for instant workflow automation  
- Accelerated client prospect enrichment by removing manual research

### Project Overview
Fully automated scraper that turns raw YC data into segmented, enriched, Clay-import-ready prospect lists — exactly the kind of pipeline GTM teams need at scale.

### Key Features
- Apify scraper for YC companies  
- Serper.dev API for real-time Google enrichment  
- Qualification & segmentation logic (B2B/SaaS tags)  
- Clay-ready JSON export + CSV backup  

### Tech Stack
- **Apify** – YC scraping  
- **Serper.dev API** – Real-time enrichment  
- **Python** – Data processing & JSON formatting  
- **Clay** – Ready-to-import exports
